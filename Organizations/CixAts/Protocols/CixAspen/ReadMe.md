## CIX Aspen


Aspen is the trading platform operated by CIX Trading Inc. powering the CIX alternative trading system for Canadian listed equities (TSX, TSXV, CBOE, CSE). It hosts the CIX ASPEN and CIX ASPEN VERT lit continuous limit order books and the CIX MIDPOINT dark book, all matched via CIX's per-security optimization cycle. Aspen disseminates a single Aspen-encoded binary market data feed and exposes one Fix 4.2 order entry gateway, both shared across the three books with the destination book selected per order.
