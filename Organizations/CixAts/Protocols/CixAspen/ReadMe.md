## CIX ASPEN


CIX ASPEN, a lit continuous limit order book for Canadian listed equities (TSX, TSXV, CBOE, CSE) on the CIX alternative trading system operated by CIX Trading Inc. Matches at calibrated sub-millisecond intervals via CIX's per-security optimization cycle, with maker/taker pricing.


### Protocols


| Protocol | Type | Note |
| --- | --- | --- |
| [MarketDataFeed](MarketDataFeed.md) | MarketData | CIX Market Data Feed |
| [OrderEntry](OrderEntry.md) | OrderEntry | CIX ATS1 Fix 4.2 Order Entry |
