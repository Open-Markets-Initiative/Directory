## CIX MIDPOINT


CIX MIDPOINT, a dark midpoint-matching book for Canadian listed equities (TSX, TSXV, CBOE, CSE) on the CIX alternative trading system operated by CIX Trading Inc. Executes exclusively at the NBBO midpoint via discrete millisecond-spaced matches calibrated per security by CIX's optimization cycle.
