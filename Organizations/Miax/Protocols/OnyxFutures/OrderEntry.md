## OnyxFutures Order Entry: Miax Futures Onyx FIX Order Interface (FOI)

Financial Information eXchange (Fix) encoding of the Miax Futures Onyx FIX Order Interface (FOI), used by trading participants to submit, modify and cancel futures orders, receive execution reports and trade drops, and request security definitions over the Miax Fix session.

### Transport

Tcp via the Miax Futures Onyx FOI Fix session for reliable ordered delivery of futures order entry, modification, cancellation, and execution report messages.
