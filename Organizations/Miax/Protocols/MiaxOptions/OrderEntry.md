## MiaxOptions Order Entry: Miax Options FIX Order Interface (FOI)

Financial Information eXchange (Fix) encoding of the Miax Options FIX Order Interface (FOI), used by members and sponsored firms to submit, modify and cancel single, cross and multileg option orders and receive execution reports over the Miax Fix session.

### Transport

Tcp via the Miax FOI Fix session for reliable ordered delivery of order entry, modification, cancellation, and execution report messages.
