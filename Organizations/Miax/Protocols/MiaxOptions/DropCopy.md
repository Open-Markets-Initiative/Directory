## MiaxOptions Drop Copy: Miax Options FIX Drop Copy (FXD)

Financial Information eXchange (Fix) encoding of the Miax Options FIX Drop Copy (FXD) interface, delivering real-time drop copies of order and execution activity to members and sponsored firms over the Miax Fix session.

### Transport

Tcp via the Miax FXD Fix session for reliable ordered delivery of drop copy execution report and order state messages.
