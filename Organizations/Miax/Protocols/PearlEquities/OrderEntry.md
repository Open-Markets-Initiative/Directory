## PearlEquities Order Entry: Miax Pearl Equities FIX Order Interface and Drop Interface (FOI)

Financial Information eXchange (Fix) encoding of the Miax Pearl Equities combined FIX Order Interface and Drop Interface (FOI), used by members and sponsored firms to submit, modify and cancel equity orders and receive execution reports and trade drops over the Miax Fix session.

### Transport

Tcp via the Miax Pearl Equities FOI Fix session for reliable ordered delivery of equity order entry, modification, cancellation, and execution report messages.
