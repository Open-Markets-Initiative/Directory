## OdxEquities Drop Copy: Odx Pts FIX Drop Copy Specification for Equities

Financial Information eXchange (Fix 4.2) encoding of the Osaka Digital Exchange Pts equities drop copy interface, a receive-only feed delivering execution report copies over the Odx Fix session.

### Transport

Tcp via the Odx Pts Fix session for reliable ordered delivery of order entry, cancellation, and execution report messages.
