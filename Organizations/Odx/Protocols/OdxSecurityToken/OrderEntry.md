## OdxSecurityToken Order Entry: Odx Pts FIX Trading Specification for Security Token

Financial Information eXchange (Fix 4.2) encoding of the Osaka Digital Exchange Pts security token trading interface, used by participants to submit and cancel security token orders and receive execution reports over the Odx Fix session.

### Transport

Tcp via the Odx Pts Fix session for reliable ordered delivery of order entry, cancellation, and execution report messages.
