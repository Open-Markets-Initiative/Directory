## HkexSecurities Drop Copy: Hkex Orion Central Gateway - Securities Market (OCG-C) FIX Drop Copy Interface

Financial Information eXchange (Fix 5.0 SP2) encoding of the Hkex Orion Central Gateway Securities Market (OCG-C) drop copy interface, a receive-only feed delivering execution report and trade capture report copies to Exchange Participants.

### Transport

Tcp via the OCG-C Fix drop copy session for reliable ordered delivery of execution report and trade capture report drop messages.
