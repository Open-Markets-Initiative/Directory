## ChinaConnect Drop Copy: Hkex China Connect Central Gateway (CCCG) FIX Drop Copy Interface

Financial Information eXchange (Fix 5.0 SP2) encoding of the Hkex China Connect Central Gateway (CCCG) drop copy interface, a receive-only feed delivering execution report copies for northbound China Stock Connect trading.

### Transport

Tcp via the CCCG Fix drop copy session for reliable ordered delivery of execution report drop messages.
