## Millennium Exchange


Millennium Exchange is the Lseg matching and trading platform acquired through MillenniumIT, hosting the London Stock Exchange order book and the venues that migrated onto it, and serving the Millennium Itch market data and Native Trading Gateway order entry interfaces.


### Protocols


| Protocol | Type | Note |
| --- | --- | --- |
| [Level2](Level2.md) | MarketData | Level 2 |
| [NativeTradingGateway](NativeTradingGateway.md) | OrderEntry | Native Trading Gateway |
| [NativeTradingGatewayRecovery](NativeTradingGatewayRecovery.md) | OrderEntry | Native Trading Gateway Recovery |
| [Trading](Trading.md) | OrderEntry | Fix Trading Gateway |
