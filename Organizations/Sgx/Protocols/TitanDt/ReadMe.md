## SGX Titan


SGX Titan derivatives trading platform built on the Nasdaq Financial Framework, hosting Singapore Exchange futures and options markets with GeniumFIX market data and reference data distribution.


### Protocols


| Protocol | Type | Note |
| --- | --- | --- |
| [MarketData](MarketData.md) | MarketData | Sgx Titan GeniumFIX Market Data |
| [ReferenceData](ReferenceData.md) | ReferenceData | Sgx Titan GeniumFIX Reference Data |
