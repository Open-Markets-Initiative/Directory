## TitanDt Reference Data: Sgx Titan GeniumFIX Reference Data

Financial Information eXchange (Fixt 1.1 session with Fix 5.0 SP2 application messages) encoding of the Sgx Titan GeniumFIX reference data interface, streaming security definitions, security definition updates, market definitions and trading session lists for the Sgx derivatives markets.

### Transport

Tcp via the Sgx GeniumFIX session for reliable ordered delivery of reference data messages, with application sequencing for recovery.
