## TitanOtc Order Entry: Sgx Titan OTC FIX API

Financial Information eXchange (Fixt 1.1 session with Fix 5.0 SP2 application messages) encoding of the Sgx Titan OTC trade registration interface, used by trading firms and brokers to register, modify and cancel over-the-counter orders and receive execution reports over the Sgx Fix session.

### Transport

Tcp via the Sgx Titan OTC Fix session for reliable ordered delivery of order registration, modification, cancellation, and execution report messages.
