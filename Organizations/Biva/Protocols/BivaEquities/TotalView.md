## BivaEquities Total View: Total View

Full depth order by order market data feed for the Biva equities market, publishing order add, execute, delete, replace and trade events using the Nasdaq Itch binary protocol.

### Transport

Udp multicast via MoldUdp64 for real time delivery of the sequenced Itch stream. Tcp via SoupBinTcp as an alternative point to point delivery of the same Itch stream.
